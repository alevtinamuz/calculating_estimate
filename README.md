# Calculating Estimate

Настольное приложение на PyQt6 для составления строительных смет: хранит справочник работ и материалов в облачной базе данных (Supabase) и позволяет быстро собрать смету на конкретный объект с автоматическим расчётом стоимости и экспортом в оформленный PDF-документ.

## Описание проекта

Приложение решает задачу, знакомую любому, кто считал строительные или ремонтные работы вручную в Excel: держать единый, постоянно пополняемый справочник цен на работы и материалы, а смету на конкретный объект собирать из этого справочника за пару кликов, а не копированием формул между листами.

Проект состоит из двух связанных экранов:

**«База данных»** — справочник работ, материалов, их категорий и разделов. Позволяет:
- просматривать и редактировать категории, работы и материалы в табличном виде;
- искать нужную позицию по названию или по ключевым словам;
- задавать связи между разделами сметы и категориями работ;
- делать резервную копию базы в файл и восстанавливать её из бэкапа.

**«Смета»** — рабочий лист конкретной сметы, где сотрудник:
- добавляет разделы, работы и материалы к каждой работе;
- выбирает позиции из справочника через выпадающий список с поиском по названию и ключевым словам (без необходимости помнить точное название);
- получает автоматический пересчёт стоимости по каждой работе, материалу, разделу и смете в целом;
- выгружает готовую смету в PDF — с логотипом компании, таблицами по разделам и итоговой суммой — одним нажатием кнопки.

## Стек технологий

- **Python 3**
- **PyQt6** — десктопный графический интерфейс
- **Supabase** (PostgreSQL) — облачное хранилище справочника работ, материалов и их категорий
- **ReportLab** — генерация PDF-сметы с кастомным оформлением и шрифтами
- **python-dotenv** — хранение ключей доступа к Supabase вне кода

## Архитектура

```
main.py                        точка входа, инициализация Supabase-клиента и главного окна
getters.py / setters.py        слой доступа к данным (CRUD-запросы к Supabase)
design/
  app_window.py                главное окно с двумя вкладками
  page_db.py                   вкладка «База данных»: таблицы, поиск, редактирование, бэкап/восстановление
  page_estimate.py              вкладка «Смета»: сборка сметы и экспорт в PDF
  classes.py                    доменные модели (SectionItem, WorkItem, MaterialItem) с расчётом сумм
  class_TableManager.py         управление таблицей сметы (модель данных, добавление/удаление строк)
  class_ComboBoxDelegate.py     кастомный выпадающий список с живым поиском по справочнику
  styles.py                     стили интерфейса
```

Работы и материалы организованы иерархически: **раздел сметы** → связанные с ним **категории работ** → сами **работы**, к каждой из которых привязан список **материалов**. Итоговая стоимость складывается снизу вверх: материал → работа → раздел → смета.

## Как запустить

1. Установить зависимости:
   ```bash
   pip install PyQt6 supabase python-dotenv reportlab
   ```

2. Создать в корне проекта файл `.env` с доступом к своей базе Supabase:
   ```
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_KEY=your-supabase-key
   ```

3. Запустить приложение:
   ```bash
   python main.py
   ```
